CAM experimental

Description

L’atelier CAM contient un ensemble de commandes cachées. Elles sont cachées par défaut car elles sont expérimentales. Une commande peut être considérée comme expérimentale pour l’une des raisons suivantes :

  • Elle est incomplète.

  • Elle présente des bogues.

  • Elle est instable.

  • Elle ne produit pas de chemins corrects, stables, sûrs.

  • Il ne s’agit pas d’une commande standard, régulièrement utilisée dans le déroulement traditionnel de la FAO.

  • Elle est mature mais n’a pas encore été déplacée vers la liste d’outils standard.

  • …​ d’autres raisons.

Activer les commandes expérimentales

Pour accéder aux commandes expérimentales masquées dans de l’atelier CAM, l’utilisateur doit les activer.

Activer les commandes Surfaçage 3D et Lignes de niveau

  1. Ouvrez le réglage des préférences via Édition  Préférences.

  2. Accédez à la page CAM  Avancé.

  3. Cochez la case Activer les fonctions dépendantes d’openCAMlib.

  4. Redémarrez FreeCAD.

Activer d’autres commandes expérimentales

  1. Ouvrez l’éditeur de paramètres via Outils  Éditer les paramètres.

  2. Une fois dans l’éditeur, le chemin d’accès est BaseApp  Preferences  Mod  CAM.

  3. Cliquez avec le bouton droit de la souris dans la zone de la liste des paramètres et sélectionnez Nouveau  Nouvel élément booléen dans le menu contextuel.

  4. Nommez le nouveau paramètre : EnableExperimentalFeatures (sensible à la casse).

  5. Définissez-le sur : True.

  6. Enregistrez les paramètres.

  7. Redémarrez FreeCAD.
