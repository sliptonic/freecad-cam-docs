CAM Exporter un modèle

CAM Exporter un modèle

Menu location

Workbenches

CAM

Default shortcut

None

Introduced in version

-

See also

CAM Feuille de configuration

Description

L’outil Exporter un modèle fournit un mécanisme pratique pour sauvegarder les définitions de tâches couramment utilisées à partir d’une tâche existante. Cela facilite la mise en place de futurs tâches, qui sont en grande partie similaires, en permettant l’importation de modèles de tâches pendant le processus de création de tâches.

Édition  Préférences…​  CAM  Préférences des tâches  Valeurs par défaut  Modèle définit le modèle par défaut.

Utilisation

  1. Sélectionnez l’option CAM  Exporter comme modèle du menu.

  2. Sélectionnez les éléments à inclure dans la fenêtre de dialogue de configuration Exporter comme modèle.

  3. Le modèle doit être enregistré dans le répertoire Macro ou le répertoire CAM, tel que configuré dans les CAM Préférences.

  4. Le nom du modèle doit suivre le modèle job_<template name>.json. Lorsqu’il est affiché dans la liste déroulante de la sélection, le préfixe job_ et l’extension sont omis.

  5. Appuyez sur le bouton OK et enregistrez le modèle.

  • Sélection du post-processeur

  • Paramètres du post-processeur

  • Nom du fichier de sortie

Brut

  • Position : position du brut

  • Profondeurs de passe

  • Vitesses de déplacement de l’outil
