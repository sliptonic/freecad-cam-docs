CAM Copy

CAM Copy

Menu location

CAM  Path Modification  Copy Operation

Workbenches

CAM

Default shortcut

None

Introduced in version

-

See also

Simple Copy, Array

The internal name of this command is CAM_OperationCopy. A separate legacy command named CAM_Copy still exists but is not available from any toolbar or menu; see the Notes below.

Description

The Copy Operation command duplicates the selected Operation(s) inside the same Job. The copy is independent: changing the original does not change the copy. If the selected object is a dressup, the base Operation and the whole dressup chain are copied.

introduced in 26.3: several Operations can be selected at once and dressup chains are copied recursively.

Usage

  1. Select one or more Operations (or dressups) in the Tree View. The command is only enabled when every selected object is an Operation or a dressup.

  2. There are several ways to invoke the command:

    • Press the Copy Operation button in the Path Modification toolbar.

    • Use the CAM  Path Modification  Copy Operation entry in the CAM menu.

    • Use the Path Modification  Copy Operation entry in the Tree View context menu.

  3. The copies are appended to the Job’s Operations group.

Properties

The copy has the same properties as the copied Operation.

Notes

  • The hidden legacy command CAM_Copy instead creates a linked copy object with Base (Link): The toolpath to be copied, and ToolController (Link). It is not available from the menus.
