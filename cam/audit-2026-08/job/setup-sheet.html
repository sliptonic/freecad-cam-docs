CAM SetupSheet

Description

The Setup Sheet is an object created automatically with every CAM Job (shown as SetupSheet under the Job in the Tree View, icon ). It holds the default values and expressions applied to every newly created Operation and Tool Controller of that Job.

Using a Setup Sheet allows the user to customize how the various property values for Operations will be calculated. The user always has the option to override the Setup Sheet values with an explicit value or change the way Setup Sheet values are calculated.

Since Setup Sheets are part of the CAM Job, values do not change the default behavior of CAM. Rather, they change only the behaviour within the context of the current Job.

Setup Sheets are particularly useful when saved with a Job Template.

In FreeCAD the term Setup Sheet means this defaults container, not the shop-floor setup document. A printable setup report for the machine operator is produced by CAM Sanity.

Usage

Edit the Setup Sheet either from the Job task panel (Setup tab: Default values; Tools tab: Rapid Speeds; Advanced tab: Operation Defaults) or by double-clicking the SetupSheet object in the Tree View. The latter opens a task panel with the tabs Operation (Depths and Heights expressions), Tool Controller (Rapid Speeds), Coolant and one tab per Operation type listing that type’s per-operation defaults as an editable table. The properties can also be changed directly in the property editor.

Properties

Tool Controller

  • HorizRapid (Speed): default horizontal rapid rate assigned (by expression) to new Tool Controllers. Only Post-Processors that output rapid feed rates use it.

  • VertRapid (Speed): default vertical rapid rate assigned to new Tool Controllers.

Coolant

  • CoolantMode (Enumeration): default coolant mode for new Operations: None, Flood or Mist.

  • CoolantModes (StringList): the list of available coolant modes.

Operation Heights

  • SafeHeightOffset (Length, default 3 mm): added to the stock top by the default safe-height expression.

  • SafeHeightExpression (String, default OpStockZMax+SetupSheet.SafeHeightOffset): the result of this expression is used to set the Safe Height of Operations.

  • ClearanceHeightOffset (Length, default 5 mm): added to the stock top by the default clearance-height expression.

  • ClearanceHeightExpression (String, default OpStockZMax+SetupSheet.ClearanceHeightOffset): the result of this expression is used to set the Clearance Height of Operations.

Operation Depths

  • StartDepthExpression (String, default OpStartDepth): the result of this expression is used to set the StartDepth property of Operations.

  • FinalDepthExpression (String, default OpFinalDepth): the result of this expression is used to set the FinalDepth property of Operations.

  • StepDownExpression (String, default OpToolDiameter): the result of this expression is used to set the StepDown property of Operations.

Linking

  • CollisionAvoidanceStrategy (Enumeration, default Retract Height) introduced in 26.3: default linking collision-avoidance strategy for new Operations that support linking (Drilling, Helix, MillFacing, Engrave, Deburr): Clearance Height, Retract Height, Line of Sight, Tool Diameter or Tool Shape.

Operation Parameters

The expressions may reference these read-only properties of the Operation:

  • OpStartDepth: the top of the Model/Stock for the operation.

  • OpFinalDepth: the bottom of the selected Base Geometry.

  • OpToolDiameter: the diameter of the Tool Bit of the operation’s Tool Controller.

  • OpStockZMax: the top of the Stock.

Referencing Setup Sheet values

Other Setup Sheet properties are referenced by the object’s internal name, e.g. SetupSheet.ClearanceHeightOffset or SetupSheet001.SafeHeightOffset for the second Job in a document. In exported Job Templates the reference is stored as ${SetupSheet} and resolved on import.

Per-operation defaults

Each Operation type registers the properties it allows as Setup Sheet defaults. When a value is set (Advanced tab of the Job task panel or the SetupSheet task panel) the Setup Sheet gains a property named after the operation and the property (e.g. ProfileStepOver); new Operations of that type receive that value, replacing any default expression (26.3 and later). When an Operation is created the Setup Sheet also applies StartDepth, FinalDepth, StepDown, SafeHeight and ClearanceHeight expressions, the CoolantMode and the CollisionAvoidanceStrategy.

Job Templates

When exporting a Job Template you can include the rapid speeds, coolant mode, operation heights, operation depths and the per-operation defaults.
