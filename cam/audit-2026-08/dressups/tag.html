CAM DressupTag

CAM DressupTag

Menu location

CAM  Path Dressup  Tag

Toolbar

Path Modification → Dressup Operations dropdown

Workbenches

CAM

Default shortcut

None

Introduced in version

-

See also

CAM DressupRampEntry, CAM DressupDogbone, CAM DressupDragKnife

Description

The CAM DressupTag command dresses up an existing Toolpath (usually a 2D Profile) to leave holding tags that keep the part attached to the Stock. Without tags a part that is not clamped can come loose when the final cut is made. The tags are broken off by hand or with a chisel and filed flat afterwards. Its tooltip reads: Creates a tag dress-up object from a selected toolpath.

A video explanation of this feature is given at: www.youtube.com/watch?v=JZ4prlR6sps

Usage

  1. Select one Operation or Dressup.

  2. There are several ways to invoke the command:

    • Select the CAM  Path Dressup  Tag option from the menu.

    • Select the Dressup Operations dropdown on the Path Modification toolbar.

    • Select the Path Dressup  Tag option from the Tree view context menu.

  3. Tags are generated automatically; adjust them in the task panel.

  4. Press Apply to preview or OK to finish.

Options

The task panel is titled Holding Tags:

  • Width: Width of the resulting holding tag.

  • Height: Height of the tag; the result may be smaller if width and angle produce a triangular shape.

  • Angle: Plunge angle for ascent and descent; 5–90°, default 45°.

  • Radius: Radius of the fillet at the top; if too big for the tag shape it is reduced, giving a dome.

  • Tags list: Every tag with its index and X, Y position and a checkbox to enable or disable it; double-click or the Edit button lets you pick a new position on the Toolpath in the 3D view. Tags are automatically disabled if they overlap the previous tag or do not lie on the base wire.

  • Buttons: Add (pick new positions in the 3D view), Remove (selected tag), Edit, Clear (introduced in 26.3 remove all tags), Enable All / Disable All, Copy (introduced in 26.3 replace all tags by the tags of another Tag dressup in the document; shown only when another one exists).

  • Auto Generate group: Min and Max number of tags per wire and the button Replace Existing Tags, which creates between Min and Max tags per bottom wire depending on its length.

On creation the dressup generates tags automatically: the number of tags per closed bottom wire is scaled between Min and Max by the wire length relative to the longest wire, and they are spaced evenly along the wire. The initial count comes from the Initial # tags preference (default 4). introduced in 26.3 Tags are generated for every closed wire of a multi-body or multi-profile Operation, and open base wires are accepted.

Properties

Base

  • Base (Link): The base Toolpath to modify.

Tag

  • Width (Length): Width of tags.

  • Height (Length): Height of tags.

  • Angle (Angle): Angle of tag plunge and ascent.

  • Radius (Length): Radius of the fillet for the tag.

  • Positions (VectorList): Locations of inserted holding tags.

  • Disabled (IntegerList): IDs of disabled holding tags.

Path

  • Approximation (Bool, hidden): introduced in 26.3 Split B-splines by arcs and ignore non-vertical arc axes (experimental); can greatly reduce the number of commands when the Toolpath contains non-horizontal arcs such as a helix. Set it from the Python console or by unhiding it in the property editor.

The Segmentation Factor property of earlier versions was removed in 26.3.

Notes

  • introduced in 26.3 The precision used to segment complex shapes while creating the tag Toolpath is the Job’s Geometry Tolerance; there is no separate property on the dressup.

Preferences

Defaults for new Tag dressups are set in Edit  Preferences  CAM  Dressups: Default width (0 = guess a reasonable value from the Toolpath), Default height (0 = half the part height; larger than the part is reduced to the part height), Default angle, Default radius and Initial # tags (default 4).

Scripting

import FreeCAD
import Path.Dressup.Gui.Tags as Tags

obj = Tags.Create(op)  # with GUI

# without GUI:
import Path.Dressup.Tags as PathTags

obj = PathTags.Create(op, "DressupTag")
obj.Positions = [FreeCAD.Vector(10, 0, 0)]
obj.Disabled = []
