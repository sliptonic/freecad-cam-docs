CAM PostSelected

CAM PostSelected

Menu location

CAM  Post Process Selected; also in the Tree View context menu of Operations

Workbenches

CAM

Default shortcut

P O

Introduced in version

26.3

See also

CAM Post, CAM Job

Description

The CAM PostSelected command (menu text: Post Process Selected; tooltip: Post Processes the selected operations) exports only the selected Operations of a Job to G-code, using the same Post-Processor flow as CAM Post. It is found in the CAM  Post Process Selected menu, in the Project Setup toolbar drop-down Post process Operations, and in the Tree View context menu of Operations.

Usage

  1. Select one or more Operations (or Dressups) of the same Job in the Tree View. The command is inactive if a Job is selected.

  2. Invoke the command:

    • Press the Post Process Selected button in the Post process Operations toolbar drop-down.

    • Select the CAM  Post Process Selected option from the menu.

    • Use the keyboard shortcut: P then O.

  3. A Post Process message box asks What needs to be exported? — press Only selected to export just the selected Operations or All (default) to export the whole Job. The box is skipped when the selection already equals the whole workplan.

  4. Post-processing continues as for CAM Post: the Post Processing dialog (Job with Machine) or the legacy flow; in the dialog the selected Operations are pre-checked on the Operations tab.

Notes

  • Check that the exported subset is safe to run without the omitted Operations (the message box reminds you).

  • Operations inside an Array with several Tool Controllers are resolved to their parent Job through the Array’s Base.

  • The command was added in 26.3.
