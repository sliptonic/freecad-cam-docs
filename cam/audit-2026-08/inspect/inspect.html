CAM Inspect

CAM Inspect

Menu location

CAM  Inspect Toolpath

Workbenches

CAM

Default shortcut

P then I

Introduced in version

-

See also

None

Description

The Inspect Toolpath command opens the CAM Inspect dialog showing the internal G-code of the selected toolpath object in a read-only code viewer with line numbers and G-code syntax highlighting (G/M words, numbers and F feed words). The toolpath has not been post-processed: coordinates are in millimetres and feed rates in mm/s, and a note at the bottom of the dialog reminds of this.

Selecting one or more lines in the viewer highlights the corresponding moves in the 3D View (drawn with the Highlight path color from Edit  Preferences  CAM  Colors) and moves the Tool Bit shape of the Operation’s Tool Controller to the start point of the selection.

introduced in 26.3: line numbers are shown. For very long toolpaths (more than 1000 lines by default, parameter MaxHighlighterSize) syntax highlighting is switched off.

This screenshot predates line numbers and the unit note in the current dialog.

Usage

  1. Select exactly one toolpath object (Operation, dressup, Array, copy or Job) whose toolpath is not empty. Otherwise "Select exactly one path object" is printed in the Report view.

  2. There are several ways to invoke the command:

    • Press the Inspect Toolpath button.

    • Select the CAM  Inspect Toolpath option from the menu.

    • Select the Inspect Toolpath option from the Tree View context menu (offered when exactly one Operation is selected).

    • Use the keyboard shortcut: P then I.

Options

  • The font and the Number/Keyword/Define name colors of the editor window follow the settings from Edit  Preferences  Editor. The 3D highlight color comes from the CAM Colors preference page.

  • The size and position of the dialog are stored in the user parameters.

Notes

  • For an Operation deactivated with Toggle Operation the viewer only shows (inactive operation).

Scripting

See also: FreeCAD Scripting Basics.

Example:

import Path.Main.Gui.Inspect
Path.Main.Gui.Inspect.show(FreeCAD.ActiveDocument.Profile)
