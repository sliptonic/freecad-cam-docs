CAM Stop

CAM Stop

Menu location

CAM  Supplemental Commands  Stop

Workbenches

CAM

Default shortcut

None

Introduced in version

-

See also

CAM Comment

Description

The CAM Stop command adds a Stop object to the Job. Depending on its Stop property it emits an optional stop (M1) or a mandatory stop (M0). An optional stop only pauses the program if the controller’s optional-stop switch is enabled; a mandatory stop always pauses and waits for the operator to resume.

Whether spindle and coolant are switched off during M0/M1 depends on the machine controller; check its documentation.

Usage

  1. Select the CAM  Supplemental Commands  Stop option from the menu. The command is not on any toolbar and has no shortcut; it is only enabled once a Job exists in the document.

  2. Set the Stop property to Optional or Mandatory.

Properties

Path

  • Stop (Enumeration): Add an optional or mandatory stop to the program. Optional (default) emits M1, Mandatory emits M0.

Notes

  • Stop objects are not Operations: they have no Tool Controller and no Active property, and cannot be toggled with Toggle Operation.

Scripting

See also: FreeCAD Scripting Basics.

Example:

import FreeCAD, Path
import Path.Op.Gui.Stop
from PathScripts import PathUtils

obj = FreeCAD.ActiveDocument.addObject("Path::FeaturePython", "Stop")
Path.Op.Gui.Stop.Stop(obj)
Path.Op.Gui.Stop._ViewProviderStop(obj.ViewObject)
obj.Stop = "Mandatory"
PathUtils.addToJob(obj)
FreeCAD.ActiveDocument.recompute()
