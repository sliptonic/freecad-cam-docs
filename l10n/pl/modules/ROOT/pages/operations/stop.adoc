== Opis

Narzędzie image:CAM_Stop.svg[width=24] xref:operations/stop.adoc[Stop] wprowadza polecenie Stop (M1). To polecenie zatrzyma uruchomiony program na kontrolerze CNC, czekając na interakcję użytkownika żeby kontynuować.

*Uwaga: to nie zatrzymuje wrzeciona.*

== Użycie

. Wciśnij przycisk image:CAM_Stop.svg[width=16] xref:operations/stop.adoc[Stop]

== Właściwości

* *Stop*: Definiuje czy Stop jest opcjonalny czy obowiązkowy.
