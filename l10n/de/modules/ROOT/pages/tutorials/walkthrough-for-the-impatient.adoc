== Ziel

Veranschaulichen der Erstellung eines Auftrags des image:Workbench_CAM.svg[width=32] xref:index.adoc[Arbeitsbereichs CAM], abgeleitet von einem 3D-Modell. Anschließend wird dialekt-richtiger G-Code für eine Ziel-CNC-Fräse erzeugt.

== Das 3D Modell

{empty}1. Das Projekt startet mit einem einfachen FreeCAD Modell entworfen im image:Workbench_PartDesign.svg[width=32] https://wiki.freecad.org/PartDesign_Workbench[Part Design] ein Würfel mit einer rechteckigen Tasche.

== Die Pfadabläufe

{empty}11. Es werden zwei Bearbeitungen hinzugefügt, um Fräsbahnen für diesen CAM-Auftrag zu erzeugen. Der Ablauf xref:operations/profile.adoc[Profil] erzeugt eine Bahn um den Kasten herum und der Ablauf xref:operations/pocket.adoc[Tasche] erzeugt eine Bahn für die Innentasche.

{empty}12. Fürs Erste werden wir es einfach halten. Die Schaltfläche image:CAM_Profile.svg[width=32] xref:operations/profile.adoc[Profil] öffnet das Konturpaneel. Nach der Bestätigung mit btn:[OK] unter Verwendung der Standardwerte, wird der der grüne Pfad um das Objekt herum sichtbar.

{empty}13. Den Taschenboden auswählen und dann mit der Schaltfläche image:CAM_Pocket_Shape.svg[width=32] xref:operations/pocket.adoc[Tasche] das Fenster Taschenform öffnen. Die Standardwerte für Basisgeometrie, Tiefen und Höhen werden verwendet und das Unter-Panel Operation ausgewählt sowie die Schrittweite in Prozent auf 50 eingestellt.

== Pfade überprüfen

Es gibt zwei Möglichkeiten, die erstellten Pfade zu überprüfen. Der G-Code kann überprüft werden, einschließlich der Hervorhebung der entsprechenden Pfadsegmente. Der Fräsprozess des CAM-Auftrags kann auch simuliert werden, um die idealisierten Werkzeugbahnen zu demonstrieren, die für die Werkzeuggeometrien zum Fräsen des Rohteils erforderlich sind.

Um den G-Code zu untersuchen, wird das Werkzeug image:CAM_Inspect.svg[width=32] xref:inspect/inspect.adoc[CAM-Befehle untersuchen] verwendet. Durch Auswählen der entsprechenden G-Code-Zeilen innerhalb des G-Code-Inspektionsfensters werden einzelne Pfadsegmente hervorgehoben.

::
  image:Path-InspectWindow.gif[]
  +
  
[.caption]
Above: Das Werkzeug xref:inspect/inspect.adoc[CAM-Befehle untersuchen] öffnet den Dialog G-Code-Inspektion

Um die Simulation zu beginnen wird das Werkzeug image:CAM_Simulator.svg[width=32] xref:inspect/simulator-legacy.adoc[CAM-Simulator] verwendet.

Geschwindigkeit und Genauigkeit einstellen und die Simulation mit der image:CAM_BPlay.svg[width=24] Wiedergabetaste (Play) starten.

::
  image:Path-Simulation.gif[]
  +
  
[.caption]
Oben: xref:inspect/simulator-legacy.adoc[CAM-Simulator] in Betrieb

Soll die Simulation beendet werden, wird die Schaltfläche btn:[Abbrechen] angeklickt, dadurch wird das für die Simulation erstellte Material entfernt. Wird btn:[OK] angeklickt, wird dieses Objekt in deinem Auftrag behalten.

== Nachbearbeitung des Auftrags

Der letzte Schritt zur Erzeugung von G-Code für die Zielfräse ist die Nachbearbeitung des Auftrags. Dabei werden die G-Codes in eine Datei ausgegeben, die auf die Ziel CNC Maschinensteuerung hochgeladen werden kann. So rufst du den Postprozessor auf:

* Das Auftragsobjekt in der https://wiki.freecad.org/Tree_View[Baumansicht] auswählen.
* Das Werkzeug image:CAM_Post.svg[width=32] xref:output/post-process.adoc[CAM Nachbearbeitung] zum Nachbearbeiten der Datei auswählen. Dies öffnet ein G-Code Fenster, in dem die endgültige Ausgabedatei vor dem Speichern überprüft werden kann.
