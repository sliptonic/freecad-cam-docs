== Beschreibung

Eine Werkzeugsteuerung enthält Eigenschaften dafür, wie ein Werkzeug in einem oder mehreren Vorgängen verwendet werden soll.

Beispielsweise kann ein Werkzeug wie ein 1/4-Zoll-Fräser mit vielen verschiedenen Spindeldrehzahlen und Vorschubgeschwindigkeiten betrieben werden. Dasselbe Werkzeug kann bei derselben Aufgabe auf unterschiedliche Weise eingesetzt werden.

== Eigenschaften

* *Vorschubgeschwindigkeit (h)*
* *Vorschubgeschwindigkeit (v)*

* *hohe Geschwindigkeit (h)*
* *hohe Geschwindigkeit (v)*

* *Spindeldrehzahl (U/min)*
* *Spindelrichtung (vorwärts/rückwärts)*

* *Werkzeugnummer*
