== Beschreibung

Das Werkzeug image:CAM_SelectLoop.svg[width=16] xref:inspect/select-loop.adoc[CAM SchleifeAuswählen] vervollständigt eine Auswahl von Kanten, die eine Schleife bilden.

== Anwendung

. Eine Kante auswählen.
. Es gibt mehrere Möglichkeiten, den Befehl aufzurufen:
* Die Schaltfläche image:CAM_SelectLoop.svg[width=16] xref:inspect/select-loop.adoc[Auswahl der Schleife abschließen] drücken.
* Die Option menu:CAM[Auswahl der Schleife abschließen] aus dem Menü wählen.
* Die Tastenkombination: kbd:[P] dann kbd:[L] drücken.
. Die verbleibenden Kanten der Schleife werden zur Auswahl hinzugefügt.

== Hinweise

* Dieser Befehl kann auch in anderen Arbeitsbereichen sehr nützlich sein.
