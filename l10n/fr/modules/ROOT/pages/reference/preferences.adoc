== Présentation

Une fois l'xref:index.adoc[atelier CAM] sélectionné, l'écran des préférences se trouve dans l'https://wiki.freecad.org/Preferences_Editor[éditeur de préférences], menu:Édition[Préférences > CAM].

Il existe cinq pages : <<interface-graphique,Interface graphique>>, <<équipements,Équipements>>, <<préférences-des-tâches,Préférences des tâches>>, <<finitions,Finitions>> et <<avancé,Avancé>>.

== Équipements

A définir

[.since]#introduced in 26.3# : les équipements machine peuvent être gérées depuis les préférences de CAM. La bibliothèque de machines et l'éditeur de machines permettent de créer et de modifier les fichiers de configuration de machine `*.fcm` utilisés par le post-traitement basé sur les machines.
