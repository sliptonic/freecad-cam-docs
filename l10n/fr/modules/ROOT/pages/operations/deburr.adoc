== Description

L'outil image:CAM_Deburr.svg[width=24] xref:operations/deburr.adoc[Ébavurage] sert principalement à ébavurer un bord.

== Utilisation

. Il existe plusieurs façons de lancer la commande :
* Appuyez sur le bouton image:CAM_Deburr.svg[width=16] xref:operations/deburr.adoc[Ébavurer].
* Sélectionnez l'option menu:CAM[Ébavurer] du menu.
. Le panneau de tâches menu:Ébavurer[] s'ouvre. Voir <<options,Options>>.
. Sélectionnez menu:Géométrie de base[].
. Spécifiez les paramètres requis.
. Appuyez sur le bouton btn:[OK].

== Options

Après avoir sélectionné la géométrie dans la section menu:Géométrie de base[] du panneau de tâches, vous pouvez appuyer sur btn:[Appliquer] pour voir le parcours de l'outil tel que défini par les options par défaut.

Ensuite, vous pouvez vérifier vos profondeurs et hauteurs, comme avec les autres commandes du parcours.

La dernière étape consiste à activer la section menu:Opération[] où vous pouvez spécifier ce qui suit :

* menu:Commande d'outil[] : sélectionnez l'outil à utiliser.
* menu:Mode de refroidissement[] : sélectionnez `Aucun`, `Jet` ou `Brouillard`.
* menu:Directions[] : sélectionnez `Sens horaire` (CW) ou `Sens anti-horaire` (CCW).
* menu:W[] : dimension de votre arête.
* menu:h[] : décalage par rapport au bas de l'outil. Il s'agit d'un dispositif de sécurité car si la pointe dépasse le bord, l'outil ne coupera plus.

== Propriétés

=== Données

.Base
* *Placement* :
* *Label* : nom d'utilisateur de l'objet (UTF-8)

.Deburr
* *Direction* : `CCW` ou `CW`.
* *Entry Point* : point d'entrée de l'opération, s'il est défini à 2, il ira dans 2 coins par rapport à la valeur par défaut.
* *Extra depth* : profondeur supplémentaire (menu:h[] dans le panneau de tâches).
* *Join* : comment joindre les segments de chanfrein, `Round` ou `Miter`.
* *Side* : le côté de l'opération, `Outside` ou `Inside`.
* *Width* : largeur du chanfrein (menu:W[] dans le panneau des tâches).

.Depth
* *Clearance Height* : hauteur nécessaire pour dégager les brides et les obstructions (définie par défaut à `OpStockZMax + SetupSheet.ClearanceHeightOffset`).
* *Safe Height* : hauteur au-dessus de laquelle les mouvements rapides sont autorisés. (définie à `OpStockZMax + SetupSheet.SafeHeightOffset`).
* *Start Depth* : profondeur de départ de l'outil, première profondeur de coupe en Z.
* *Step Down* : pas de descente incrémentale de l'outil

.Op Values
* *Op Stock ZMax* : valeur Z maximale du brut.
* *Op Stock ZMin* : valeur Z minimale du brut.
* *Op Tool Diameter* : diamètre de l'outil.

.Path
* *Active* : mis à `false`, pour empêcher l'opération de générer du code.
* *Base* : géométrie de base pour cette opération, des arêtes ou une face.
* *Comment* : commentaire facultatif pour cette opération.
* *Coolant Mode* : mode de refroidissement pour cette opération.
* *Cycle Time* : durée estimée du cycle pour cette opération.
* *Tool Controller* : contrôleur d'outil qui sera utilisé pour calculer le parcours.
* *User Label* : étiquette attribuée par l'utilisateur.
