== Description

La commande image:CAM_Engrave.svg[width=24] xref:operations/engrave.adoc[Gravure] sert principalement à graver une image:Draft_ShapeString.svg[width=24]https://wiki.freecad.org/Draft_ShapeString[Draft Forme à partir d'un texte] sur une pièce. Elle peut également être utilisée avec d'autres géométries 2D planes, par exemple des formes importées au format SVG.

== Utilisation

. Il existe plusieurs façons de lancer la commande :
* Cliquez sur le bouton image:CAM_Engrave.svg[width=16] xref:operations/engrave.adoc[Graver].
* Sélectionnez l'option menu:CAM[Graver] du menu.
. Dans la section menu:Géométrie de base[], sélectionnez la géométrie à graver.
* Une image:Draft_ShapeString.svg[width=24]https://wiki.freecad.org/Draft_ShapeString[Draft Forme à partir d'un texte] peut être utilisée.
* D'autres géométries 2D planes, telles que des formes importées au format SVG, peuvent également être utilisées.
* Dans la mesure du possible, sélectionnez la forme plane entière plutôt que de sélectionner chaque arête dans la https://wiki.freecad.org/3D_View[vue 3D].
. Dans la section menu:Profondeurs[], vérifiez et ajustez les paramètres de profondeur selon vos besoins.
. Confirmez l'opération.

== Options

* *Base* : la géométrie à graver.
* *Supprimer* : supprime la sélection géométrique en cours.
