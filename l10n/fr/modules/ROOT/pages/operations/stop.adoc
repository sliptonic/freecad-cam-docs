== Description

La commande image:CAM_Stop.svg[width=24] xref:operations/stop.adoc[Arrêter] insère une commande d'arrêt (M1). Cette commande suspendra le programme en cours d'exécution sur le contrôleur CNC dans l'attente d'une nouvelle action de l'utilisateur.

*Remarque : cela n'arrête pas la broche.*

== Utilisation

. Pressez le bouton image:CAM_Stop.svg[width=16] xref:operations/stop.adoc[Arrêter]

== Propriétés

* *Stop* : définit si l'arrêt est facultatif ou obligatoire.
