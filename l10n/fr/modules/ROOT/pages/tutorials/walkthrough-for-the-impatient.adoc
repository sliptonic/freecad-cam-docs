== Objectif

Démonstration de la création d'une tâche de l'image:Workbench_CAM.svg[width=32] xref:index.adoc[atelier CAM] dérivé d'un modèle 3D, puis création du G-Code pour dialoguer avec une fraiseuse CNC cible.

== Le modèle 3D

{empty}1. Le projet commence par un simple modèle FreeCAD conçu dans image:Workbench_PartDesign.svg[width=32] https://wiki.freecad.org/PartDesign_Workbench[PartDesign], un cube avec une poche rectangulaire,

::
  image:Path-SquarePocketModel.png[]

[.caption]
Au dessus: créé dans l'image:Workbench_PartDesign.svg[width=24] https://wiki.freecad.org/PartDesign_Workbench[atelier PartDesign] incluant un Corps, une boîte avec une cavité, basée sur une esquisse orientée dans le image:View-top.svg[width=16] plan XY.

{empty}2. Une fois le modèle 3D terminé, passez à l'image:Workbench_CAM.svg[width=32] xref:index.adoc[atelier CAM] via le https://wiki.freecad.org/Std_Workbench[sélecteur d'atelier] (menu déroulant)

* Appuyez sur le bouton image:CAM_Job.svg[width=24] xref:job/job.adoc[Tâche] dans la barre d'outils.
* Utilisation du raccourci clavier kbd:[P] puis kbd:[J].
* En utilisant l'entrée menu:CAM[Tâche] du menu supérieur.

{empty}5. La fenêtre de dialogue de la tâche s'ouvre dans la fenêtre Tâche et la fenêtre de vue du modèle affiche le brut sous la forme de cube en filaire entourant le corps de base. L'onglet Configuration est sélectionné.

== Les opérations d'usinage

{empty}11. Deux opérations seront ajoutées pour générer des parcours de fraisage pour cette tâche. L'opération xref:operations/profile.adoc[Profilage] crée un parcours d'usinage autour de la boîte et l'opération xref:operations/pocket.adoc[Poche] crée un parcours pour la poche intérieure.

{empty}12. Pour l'instant, nous allons garder les choses simples. Le bouton image:CAM_Profile.svg[width=32] xref:operations/profile.adoc[Profilage] ouvre le panneau Profilage. Après avoir confirmé avec btn:[OK] en utilisant les valeurs par défaut, le parcours d'usinage autour de l'objet est visible en vert.

{empty}13. Sélectionner le bas de la poche puis le bouton image:CAM_Pocket_Shape.svg[width=32] xref:operations/pocket.adoc[Poche] ouvre la fenêtre Forme de la poche. Les valeurs par défaut de la géométrie de base, des profondeurs et des hauteurs sont utilisées, le sous-panneau Opération est sélectionné et le pourcentage de dépassement est défini sur 50.

== Vérification des parcours d'usinage

Il existe deux manières de vérifier les parcours d'usinage créés. Le G-code peut être inspecté, notamment en mettant en évidence les segments de parcours d'usinage correspondants. Le processus de fraisage de la tâche d'usinage peut également être simulé pour illustrer les parcours d’outil optimisés, nécessaires aux géométries d’outil pour fraiser le brut.

Pour inspecter le G-code, utilisez l'outil image:CAM_Inspect.svg[width=32] xref:inspect/inspect.adoc[CAM Inspecter des commandes]. La sélection des lignes de G-code correspondantes dans la fenêtre Inspection du G-code met en surbrillance des segments de parcours d'usinage individuels.

::
  image:Path-InspectWindow.gif[]
  +
  
[.caption]
Ci-dessus: L'outil xref:inspect/inspect.adoc[CAM Inspecter des commandes] ouvre la fenêtre de dialogue Inspection G-Code

Démarrer la simulation en utilisant l'outil image:CAM_Simulator.svg[width=32] xref:inspect/simulator-legacy.adoc[CAM Simulateur de parcours] .

Réglez la vitesse et la précision et lancez la simulation avec le bouton de lecture image:CAM_BPlay.svg[width=24].

::
  image:Path-Simulation.gif[]
  +
  
[.caption]
Ci-dessus : xref:inspect/simulator-legacy.adoc[Simulateur de parcours] en cours

Si vous souhaitez mettre fin à la simulation, cliquez sur le bouton btn:[Annuler] pour supprimer le brut créé pour la simulation. Si vous cliquez sur btn:[OK], cet objet sera conservé dans votre travail.

== Post-traiter la tâche

La dernière étape pour générer le G-code pour la fraiseuse cible consiste à post-traiter la tâche. Cela envoie les G-codes dans un fichier pouvant être chargé sur le contrôleur de machine CNC cible. Pour appeler le post-processeur:

* Sélectionnez l'objet Tâche dans la https://wiki.freecad.org/Tree_view[vue en arborescence]
* Sélectionnez l'outil image:CAM_Post.svg[width=32] xref:output/post-process.adoc[CAM Post-traitement] pour post-traiter le fichier. Cela ouvre une fenêtre de G-code permettant d'inspecter le fichier de sortie final avant son enregistrement.
