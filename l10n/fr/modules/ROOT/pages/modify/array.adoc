== Description

La commande image:CAM_Array.svg[width=24] xref:modify/array.adoc[Réseau] crée un nouveau parcours en dupliquant un autre parcours plusieurs fois à une certaine distance d'intervalle.

== Utilisation

. Sélectionnez l'opération que vous souhaitez répéter
. Pressez le bouton image:CAM_Array.svg[width=16] xref:modify/array.adoc[Réseau]
. Pressez btn:[Appliquer]
. Ajustez les propriétés souhaitées dans la fenêtre de dialogue des données

== Propriétés

* *Type* : type de réseau : `Linear1D`, `Linear2D` ou `Polar`
* *Offset* : espace entre les copies du réseau pour chaque direction
* *Copies* : nombre de copies (sans compter l'original) pour chaque direction

[.since]#introduced in 26.3# : le contrôle du jitter basé sur un pourcentage utilisé auparavant a été remplacé par *UseJitter*. Le jitter peut être appliqué aux réseaux polaires, et le jitter de rotation aléatoire est disponible pour tous les types de réseaux.

* *UseJitter* : active les décalages et rotations aléatoires pour les copies générées de réseaux
* *JitterMagnitude* : translation aléatoire maximale dans chaque direction
* *JitterAngle* : angle de rotation aléatoire maximal
* *JitterSeed* : valeur de départ permettant de reproduire le jitter
