== Description

La commande image:CAM_Inspect.svg[width=24] xref:inspect/inspect.adoc[Inspecter des commandes] permet l'inspection du G-code interne de FreeCAD d'une opération de CAM.

image:Path_inspector.jpg[]

== Utilisation

. Sélectionnez un objet CAM
. Il existe plusieurs façons de lancer la commande :
* Appuyez sur le bouton image:CAM_Inspect.svg[width=16] xref:inspect/inspect.adoc[Inspecter les commandes].
* Sélectionnez l'option menu:CAM[Inspecter les commandes] du menu.
* Sélectionnez l'option menu:Inspecter les commandes[] dans le menu contextuel de l'https://wiki.freecad.org/Tree_View[arborescence].
* Utilisez le raccourci clavier : kbd:[P] puis kbd:[I].

== Options

* La police et les couleurs de la fenêtre d'édition suivent les paramètres de menu:Édition[Préférences > Éditeur].
