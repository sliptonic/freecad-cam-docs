== Overview

After selecting the xref:index.adoc[CAM Workbench] the preferences screen is found in the https://wiki.freecad.org/Preferences_Editor[Preferences Editor], menu:Edit[Preferences > CAM].

There are five pages: <<gui,GUI>>, <<assets,Assets>>, <<job-preferences,Job preferences>>, <<dressups,Dressups>>, and <<advanced,Advanced>>.
