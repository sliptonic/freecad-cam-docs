== Description

The image:CAM_Array.svg[width=24] xref:modify/array.adoc[CAM Array] command creates a new path by duplicating another path several times at a certain interval distance.

== Usage

. Select the operation you want to repeat
. Press the image:CAM_Array.svg[width=16] xref:modify/array.adoc[Array] button
. Press btn:[Apply]
. Adjust the desired properties at the data box

== Properties

* *Type*: The array type: `Linear1D`, `Linear2D` or `Polar`
* *Offset*: The spacing between the array copies for each direction
* *Copies*: The number of copies (not counting the original) for each direction

[.since]#introduced in 26.3#: The previous percentage-based jitter control has been replaced by *UseJitter*. Jitter can be applied to polar arrays, and random rotation jitter is available for all array types.

* *UseJitter*: Enables random offsets and rotations for generated array copies
* *JitterMagnitude*: The maximum random translation in each direction
* *JitterAngle*: The maximum random rotation angle
* *JitterSeed*: The seed value for repeatable jitter
