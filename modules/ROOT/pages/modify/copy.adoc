NOTE: The internal name of this command is `CAM_OperationCopy`. A separate legacy command named `CAM_Copy` still exists but is not available from any toolbar or menu; see the Notes below.

== Description

The image:CAM_OpCopy.svg[width=24] xref:modify/copy.adoc[Copy Operation] command duplicates the selected Operation(s) inside the same Job. The copy is independent: changing the original does not change the copy. If the selected object is a dressup, the base Operation and the whole dressup chain are copied.

[.since]#introduced in 26.3#: several Operations can be selected at once and dressup chains are copied recursively.

== Usage

. Select one or more Operations (or dressups) in the https://wiki.freecad.org/Tree_View[Tree View]. The command is only enabled when every selected object is an Operation or a dressup.
. There are several ways to invoke the command:
* Press the image:CAM_OpCopy.svg[width=16] xref:modify/copy.adoc[Copy Operation] button in the Path Modification toolbar.
* Use the menu:CAM[Path Modification > Copy Operation] entry in the CAM menu.
* Use the menu:Path Modification[Copy Operation] entry in the Tree View context menu.
. The copies are appended to the Job's Operations group.

== Properties

The copy has the same properties as the copied Operation.

== Notes

* The hidden legacy command `CAM_Copy` instead creates a linked copy object with *Base* (`Link`): The toolpath to be copied, and *ToolController* (`Link`). It is not available from the menus.
