== Description

The image:CAM_Engrave.svg[width=24] xref:operations/engrave.adoc[CAM Engrave] command is primarily for engraving a image:Draft_ShapeString.svg[width=16] https://wiki.freecad.org/Draft_ShapeString[Draft ShapeString] onto a part. It can also be used with other flat 2D geometry, for example imported SVG-based shapes.

== Usage

. There are several ways to invoke the command:
* Press the image:CAM_Engrave.svg[width=16] xref:operations/engrave.adoc[Engrave] button.
* Select the menu:CAM[Engrave] option from the menu.
. In the menu:Base Geometry[] section, select the geometry to engrave.
* A image:Draft_ShapeString.svg[width=16] https://wiki.freecad.org/Draft_ShapeString[Draft ShapeString] can be used.
* Other flat 2D geometry, such as imported SVG-based shapes, can also be used.
* When possible, select the whole flat shape instead of selecting many individual edges in the https://wiki.freecad.org/3D_View[3D View].
. In the menu:Depths[] section, check and adjust the depth settings as required.
. Confirm the operation.

== Options

* *Base*: The geometry to engrave.
* *Clear*: Clears the current geometry selection.
