== Description

The image:CAM_Custom.svg[width=24] xref:operations/custom.adoc[CAM Custom] command inserts an Operation which is built from hand coded custom G-code.

The Custom operation is a regular Operation with a Tool Controller and coolant mode; the Post-Processor emits the tool change and spindle commands for the selected Tool Controller before the custom G-code. Only write M6/M3 codes yourself if the snippet must use a different tool or spindle setting than the Tool Controller.

Note that feed rates (F words) in custom G-code are interpreted in FreeCAD's internal units, millimetres per second, and are converted to the machine units by the Post-Processor (see the note in xref:inspect/inspect.adoc[Inspect Toolpath]).

== Usage

. Select menu:CAM[Supplemental Commands > Custom]. The command is not on any toolbar; a xref:job/job.adoc[Job] must exist in the document.
. In the task panel choose the G-code source and type or load the G-code. Refer to the xref:reference/scripting.adoc[CAM scripting] page for supported G-code commands.
. Select the Tool Controller and press btn:[OK].

== Task panel

* *G-code source*: `Text` to type the G-code in the editor below, or `File` to read it from a file. [.since]#introduced in 26.3#
* Editor: one G-code command per line; line numbers are displayed. [.since]#introduced in 26.3#
* *File name* and btn:[…]: path of the G-code file (relative paths are resolved against the document's folder). [.since]#introduced in 26.3#
* Tool Controller tab: Tool Controller and coolant mode used for this Operation.

=== Expressions

[.since]#introduced in 26.3#: an https://wiki.freecad.org/Expressions[expression] can be embedded anywhere in a line by enclosing it in double curly braces, for example `G0 Z{{VarSet.HeightZ.Value+5}}` or `G0 X{{Profile.Path.Commands[3].x}} Y{{Profile.Path.Commands[3].y}}`. The expression is evaluated in the context of the Custom object each recompute; if it cannot be evaluated, a warning with the line number is printed and the toolpath is cleared.

=== Error handling

The generated toolpath is wrapped in the comments `(Begin Custom)` and `(End Custom)`. Lines that cannot be parsed as G-code are skipped and reported in the https://wiki.freecad.org/Report_view[Report view] with their line numbers. Blank lines are allowed. [.since]#introduced in 26.3#: lines from the `Text` source (not from a file) are marked as allowed-unsupported so that non-standard codes pass through to the Post-Processor unchanged.

== Properties

.Path
* *Source* (`Enumeration`): Source of the G-code: `Text` (default) or `File`. [.since]#introduced in 26.3#
* *Gcode* (`StringList`): The G-code to be inserted, one command per entry (only visible for *Source* = `Text`).
* *GcodeFile* (`File`): File containing the G-code to be inserted (only visible for *Source* = `File`). [.since]#introduced in 26.3#
* *ToolController* (`Link`), *CoolantMode* (`Enumeration`), *Active* (`Bool`), *Comment* (`String`), *UserLabel* (`String`), *CycleTime* (`String`): standard Operation properties from the xref:index.adoc[operation base].

== Notes

* xref:modify/simple-copy.adoc[Simple Copy] creates a Custom operation pre-filled with the G-code of the copied Operations, so the copy can be edited with this task panel.

== Scripting

See also: https://wiki.freecad.org/FreeCAD_Scripting_Basics[FreeCAD Scripting Basics].

Example:

[source,python]
----
import Path.Op.Custom

obj = Path.Op.Custom.Create("Custom", parentJob=job)
obj.Gcode = ["G0 Z10", "G0 X0 Y0"]
obj.ToolController = job.Tools.Group[0]
FreeCAD.ActiveDocument.recompute()
----
