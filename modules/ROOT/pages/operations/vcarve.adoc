== Description

The image:CAM_Vcarve.svg[width=24] xref:operations/vcarve.adoc[CAM Vcarve] command is primarily for center-line engraving a image:Draft_ShapeString.svg[width=16] https://wiki.freecad.org/Draft_ShapeString[Draft ShapeString] onto a part. However, it may be useful for other kinds of 2D.

Unlike engraving which follows the lines in the shapestring, V-carving uses a V-shaped cutter and attempts to clear the area by moving the cutter down the center of the region and varying the depth of cut. Since a v-cutter radius varies with the depth, the width of cut varies as well. The result is a more natural looking cut, particularly for serif fonts.

image::Engravepath.png[]

 

image::Vcarvepath.png[Example Vcarving Path]

 

image::Vcarved.png[]

 

image::Scrolltest.png[]

The V-carve algorithm calculates a path down the center-line of a region using a Voronoi diagram. This center-line is the path the tool will follow in the XY-plane. It next calculates a 'maximum inscribed circle' along the path. This is the largest circle that can be drawn at that point and remain entirely inside the clearing area. Using the circle radius and the tip angle of the cutter, the depth of cut is calculated.

[.since]#introduced in 26.3#: Routing can use virtual edge backtracking. If the next cutting start point is reachable through an already-carved path, or through an edge that will be carved next, the operation can follow that edge instead of a retract, rapid move and plunge.

== Usage

=== Prepare the shapes to engrave

* image:Draft_ShapeString.svg[width=16] https://wiki.freecad.org/Draft_ShapeString[Draft ShapeStrings] are usable out of the box
* SVG files require some massaging, both in the editor and in the image:Workbench_Draft.svg[width=16] https://wiki.freecad.org/Draft_Workbench[Draft Workbench]:
** In the editor (e.g. https://www.inkscape.org[Inkscape]): make sure the file only contains paths and that the paths are ungrouped; make sure there are no self-intersecting paths, (in Inkscape) use Path → Simplify and union to join paths that overlap.
** Switch to the image:Workbench_Draft.svg[width=16] https://wiki.freecad.org/Draft_Workbench[Draft Workbench] in https://wiki.freecad.org/Std_Workbench[workbench dropdown list]
** Import the SVG using menu:File[Import > select "SVG as geometry"]

=== Create the Vcarve operation

* Switch to the image:Workbench_CAM.svg[width=16] xref:index.adoc[CAM Workbench] in the https://wiki.freecad.org/Std_Workbench[workbench dropdown menu]
* Add a job, use the objects named `Face<number>` (or the ShapeString) as a base, add a v-bit tool controller, set feeds, speeds, etc.
* The operation only supports one object (either a single Face object, or a ShapeString) so for each object:
** Select menu:CAM[Vcarve] from the top menu. This opens the configuration panel.
** Open the kbd:[Base Geometry] tab and add all faces of the ShapeString, or the face of a single Face object obtained above
** Press btn:[Apply] and inspect the generated path; if necessary, adjust operation parameters (Threshold can be set higher in most situations)
** Press btn:[OK] to finish
