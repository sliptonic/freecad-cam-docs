== Description

The Area Workplane command (tooltip: "Selects a workplane for a feature area") assigns a planar shape as the *WorkPlane* of a xref:misc/area.adoc[FeatureArea]. The workplane defines the plane used for coplanarity checks and, with *SectionMode* = `Workplane`, the starting height of Z sections.

== Usage

. Select exactly one FeatureArea object and one planar shape: a whole 2D object, or a single face or edge sub-element of an object (an edge is expanded to its wire). The command is enabled only when a FeatureArea is part of the selection.
. Press the image:CAM_Area_Workplane.svg[width=16] Area Workplane button. The shape is stored in the area's *WorkPlane* property and the area is made visible. Errors such as "Select one feature area only", "Select one sub shape object for plane only" or "Selected shape is not 2D" are printed in the https://wiki.freecad.org/Report_view[Report view].

== Properties

This command creates no object of its own. It sets the *WorkPlane* (`PartShape`) property of the selected xref:misc/area.adoc[Area].

== Scripting

See also: https://wiki.freecad.org/FreeCAD_Scripting_Basics[FreeCAD Scripting Basics].

Example:

[source,python]
----
import PathCommands

area = FreeCAD.ActiveDocument.FeatureArea
area.WorkPlane = PathCommands.findShape(FreeCAD.ActiveDocument.Sketch.Shape, 'Edge1', 'Wires')
FreeCAD.ActiveDocument.recompute()
----
