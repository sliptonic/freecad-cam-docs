== Description

The image:CAM_Datums.svg[width=24] xref:job/fixture.adoc[Fixture] command sets the Work Offset Coordinate Fixture of the machine CNC controller. It can only be invoked from Python (`FreeCADGui.runCommand("CAM_Fixture")`).

G54 to G59 and the extended G59.1 to G59.9 select one of the work offsets stored in the CNC controller; G53 (machine coordinates) is not selectable. Which extended offsets exist depends on the controller.

NOTE: In the CAM Workbench, _Fixture_ means a work coordinate system selection, not the physical workholding device.

== Fixtures on the Job

Since 1.0 the work coordinate systems are selected on the Job:

* The *Fixtures* property (default G54) lists the systems to output.
* *OrderOutputBy* (Fixture, Tool, Operation) controls grouping.
* *SplitOutput* writes one file per group.

In the Job task panel these are on the menu:Output[] tab under *Work Coordinate Systems* (checklist G54 to G59.9, Order by, Split Output). The Post-Processor emits the fixture command before the Operations of each group.

When the Job has a Machine, the xref:output/post-process.adoc[Post Process] dialog's Overview tab shows a *Fixtures* checklist ([.since]#introduced in 26.3#); unchecking a fixture omits it from that export without changing the Job.

== Properties

[.until]#1.0 and earlier#

* *Fixture*: the work offset (G54 … G59.9).
* *Active*: when false the object emits no G-code.

== Scripting

Set the work coordinate systems on the Job instead:

[source,python]
----
job.Fixtures = ['G54', 'G55']
job.OrderOutputBy = 'Fixture'
job.SplitOutput = True
----
