== Description

The image:CAM_SimulatorGL.svg[width=24] xref:inspect/simulator.adoc[CAM SimulatorGL] command is the default simulator and an alternative to the xref:inspect/simulator-legacy.adoc[Legacy CAM Simulator], which remains available in the same toolbar group (the parameter `DefaultSimulatorLegacy` swaps the order). Its tooltip reads: _Simulates G-code on stock_. It renders with low-level OpenGL in its own view and is meant to be faster and more precise than the old simulator. [.since]#26.3 and later#: the view opens as a tab in the main window next to the 3D view, follows the navigation style set in the Preferences, and accepts the standard view commands (orthographic/perspective, zoom in/out, fit all).

== Usage

. There are several ways to invoke the command:
* Press the image:CAM_SimulatorGL.svg[width=16] xref:inspect/simulator.adoc[CAM Simulator] button.
* Select the menu:CAM[image:CAM_SimulatorGL.svg[width=16] CAM Simulator] option from the menu.
* Use the keyboard shortcut: kbd:[P] then kbd:[N].
. Select the Job in the Job drop-down (the Job of the current selection is preselected, [.since]#26.3 and later# also from a selected Operation).
. Uncheck Operations that should not be simulated; with *Follow operations visibility* checked, hidden Operations start unchecked. [.since]#introduced in 26.3#
. Set Accuracy (Low, Medium, High).
. Press the image:CAM_BPlay.svg[width=24] (Activate / resume simulation) button to open the simulator view. Play is disabled when no Operation is checked.
* Use the buttons below the view, left to right: Play simulation, Single step simulation, Decrease simulation speed ([.since]#introduced in 1.1#), Increase simulation speed (current multiplier shown as xN), Reset camera ([.since]#introduced in 1.1#), Toggle view simulation/model, Toggle turn table animation, Show/hide tool path, Toggle ambient occlusion.
* The slider above the buttons scrubs through the Toolpath.
* Navigate the view with the same mouse and keyboard controls as the https://wiki.freecad.org/3D_view[3D view] (see https://wiki.freecad.org/Mouse_navigation[Mouse navigation]). [.since]#26.3 and later#
. Close the task panel with btn:[Close].

== Task panel

* *Accuracy*: simulation quality, Low, Medium or High; lower quality is faster.
* *Job*: the Job to simulate.
* *Follow operations visibility*: preselect Operations according to their visibility in the 3D view (stored in the preference SimulatorFollowsVisibility). [.since]#introduced in 26.3#
* *Operations list*: Active Operations to include.

== Notes

* The simulator builds a revolved profile from the Tool Bit solid of each Tool Controller, so all Tool Shapes are represented; the Tool Bit objects themselves are not modified ([.since]#26.3 and later#).
* Drilling cycles including G84 retract are expanded.
* Rotary axis words are not simulated. Use xref:inspect/camotics.adoc[CAMotics] or another external simulator for rotary Toolpaths.
* [.since]#introduced in 1.1#: Reset camera and Decrease simulation speed buttons were added.
