== Description

The image:CAM_Inspect.svg[width=24] xref:inspect/inspect.adoc[CAM Inspect] command allows inspection of the internal FreeCAD G-code dialect contents of a CAM Operation object.

image:Path_inspector.jpg[]

== Usage

. Select a CAM object.
. There are several ways to invoke the command:
* Press the image:CAM_Inspect.svg[width=16] xref:inspect/inspect.adoc[Inspect Toolpath] button.
* Select the menu:CAM[Inspect Toolpath] option from the menu.
* Select the menu:Inspect Toolpath[] option from the https://wiki.freecad.org/Tree_View[Tree View] context menu.
* Use the keyboard shortcut: kbd:[P] then kbd:[I].
