== Description

The image:CAM_SelectLoop.svg[width=24] xref:inspect/select-loop.adoc[CAM SelectLoop] command completes a selection of edges that form a loop.

== Usage

. Select an edge.
. There are several ways to invoke the command:
* Press the image:CAM_SelectLoop.svg[width=16] xref:inspect/select-loop.adoc[Finish Selecting Loop] button.
* Select the menu:CAM[Finish Selecting Loop] option from the menu.
* Use the keyboard shortcut: kbd:[P] then kbd:[L].
. The remaining edges of the loop are added to the selection.

== Notes

* This command can also be very useful in other workbenches.
