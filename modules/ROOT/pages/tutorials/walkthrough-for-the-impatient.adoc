== Aim

Demonstrating the creation of a image:Workbench_CAM.svg[width=32] xref:index.adoc[CAM Workbench] Job derived from a 3D Model. Then generating dialect-correct G-Code for a target CNC mill.

== The Path Operations

{empty}11. Two operations will be added to generate milling paths for this CAM Job. The xref:operations/profile.adoc[Profile] operation creates a path around the box and the xref:operations/pocket.adoc[Pocket] operation creates a path for the inner pocket.

{empty}12. For now we will keep it simple. The image:CAM_Profile.svg[width=32] xref:operations/profile.adoc[Profile] button opens the Contour panel. After confirming with btn:[OK] using the default values, see the green path around the object is visible.

{empty}13. Selecting the bottom of the pocket and then the image:CAM_Pocket_Shape.svg[width=32] xref:operations/pocket.adoc[Pocket] button opens the Pocket Shape window. The default values for Base Geometry, Depths, and Heights are used, and the Operation subpanel is selected, and the Step Over Percent is set at 50.

== Verifying Paths

There are two ways to verify the created paths. The G-Code can be inspected, including highlighting the corresponding path segments. The milling process of the CAM Job can also be simulated to demonstrate the idealized tool paths, required for the Tool geometries to mill the Stock.

To inspect the G-Code use the image:CAM_Inspect.svg[width=32] xref:inspect/inspect.adoc[CAM Inspect] tool. Selecting the corresponding G-Code lines within the G-Code Inspection window highlights individual path segments.

::
  image:Path-InspectWindow.gif[]
  +
  
[.caption]
Above: xref:inspect/inspect.adoc[CAM Inspection] tool opens the G-Code Inspection dialog

To start the simulation use the image:CAM_Simulator.svg[width=32] xref:inspect/simulator-legacy.adoc[CAM Simulator] tool.

Adjust speed and accuracy and start the simulation with the image:CAM_BPlay.svg[width=24] (Play) button.

::
  image:Path-Simulation.gif[]

[.caption]

If you want to end the simulation click the btn:[Cancel] button, it will remove the stock created for the simulation. If you click btn:[OK] this object will be kept in your Job.

== Postprocess the Job

The final step to generate G-Code for the target mill is to postprocess the Job. This outputs the G-Codes to a file that can be uploaded to the target CNC machine controller. To invoke the Postprocessor:

* Select the Job object in the https://wiki.freecad.org/Tree_View[Tree View]
* Select the image:CAM_Post.svg[width=32] xref:output/post-process.adoc[CAM Postprocessing] tool to postprocess the file. This opens a G-Code window allowing inspection of the final output file before it is saved.
