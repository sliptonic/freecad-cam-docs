== Aim

Demonstrating the creation of a image:Workbench_CAM.svg[width=32] xref:index.adoc[CAM Workbench] Job derived from a 3D Model. Then generating dialect-correct G-Code for a target CNC mill.

=== Job Setup

{empty}5. The Job Edit task panel opens on the Setup tab, and the model view shows the Stock as a wire-frame box surrounding the Body: the Stock group defaults to "Extend model's bounding box" with Ext. X/Y/Z values. The Alignment and Origin & Orientation groups let you move the model so that its machining origin is in a corner (btn:[Set Origin], btn:[X=0] / btn:[Y=0] / btn:[Z=0], btn:[Center in Stock]).

=== Job General

{empty}6. The General tab ([.since]#introduced in 26.3#) holds the Job label, the list of Models, a Description and the Machine selector. Choosing a Machine (`.fcm`) determines the post-processor and its output options; press btn:[New Machine] to open the Machine Editor if none exists. You may leave it empty to use the legacy post-processor selection on the Output tab.

=== Job Output

{empty}7. The Output tab sets the Output file template, the Processor (only used when no Machine is assigned) and its Arguments (mouse over to show tooltips of common arguments), and the Work Coordinate Systems (G54-G59) with Order by and Split Output.

=== Job Tools

::
  image:Path-JobTools.png[]
  +
  
[.caption]
Above: xref:job/job.adoc[CAM Job] Edit dialog with the Tools tab selected (pre-1.0 screenshot)

{empty}8. On the Tools tab select the default Tool Controller (TC: 5mm Endmill) and press btn:[Edit] to open the Tool Controller Editor. (btn:[Add] opens the Toolbit Selector to create further Tool Controllers from the Tool Library.)

{empty}9. Set the Tool Number to match the machine's tool slot, enter Horizontal and Vertical feed (e.g. `120 mm/min`) and a spindle speed (`2000 rpm`, Forward). The editor also offers Lead-in, Lead-out and Ramp feeds and Horizontal/Vertical rapids. The btn:[Feeds and Speeds Wizard] ([.since]#introduced in 26.3#) can compute values from the stock material and the Tool Bit.

{empty}10. Tool geometry (Diameter, Cutting edge height, Flutes, Length ...) is defined on the Tool Bit, not the Tool Controller. Double-click the Tool Bit under the Tool Controller in the tree, or open the Toolbit Library Manager (menu:CAM[Toolbit Library Manager]) to edit it in the Toolbit Parameter Editor. The simulator uses the Tool Shape, so no extra angles need to be entered.

{empty}11. The values are confirmed with btn:[OK]

Note: tools are kept in Tool Libraries; use image:CAM_ToolBitDock.svg[width=24] xref:tools/add-toolbit.adoc[Add Toolbit] (kbd:[P] kbd:[T]) to add library tools to the Job and image:CAM_ToolBitLibraryOpen.svg[width=24] xref:tools/library-manager.adoc[Toolbit Library Manager] to create or edit them.

== The Toolpath Operations

{empty}12. Two operations will be added to generate milling toolpaths for this CAM Job. The xref:operations/profile.adoc[Profile] operation creates a toolpath around the box and the xref:operations/pocket.adoc[Pocket Shape] operation creates a toolpath for the inner pocket.

{empty}13. For now we will keep it simple. With nothing selected, press the image:CAM_Profile.svg[width=32] xref:operations/profile.adoc[Profile] button. The Profile task panel opens; the Operation page shows Cut side (Outside), Direction (CW) and Use Compensation. Press btn:[OK] to profile the whole model with the default values; a green toolpath appears around the box.

{empty}14. Select the bottom face of the pocket and press the image:CAM_Pocket_Shape.svg[width=32] xref:operations/pocket.adoc[Pocket Shape] button. The Pocket Shape panel opens. The default values for Base Geometry, Depths, and Heights are used; on the Operation page set Step over to `50` % .

== Verifying Toolpaths

There are two ways to verify the created toolpaths. The G-Code can be inspected, including highlighting the corresponding toolpath segments. The milling process of the CAM Job can also be simulated to demonstrate the idealized toolpaths, required for the Tool Bit geometries to mill the Stock.

To inspect the G-Code select an operation and use the image:CAM_Inspect.svg[width=32] xref:inspect/inspect.adoc[Inspect Toolpath] tool (kbd:[P] kbd:[I], also in the tree context menu). Selecting the corresponding G-Code lines within the G-Code Inspection window highlights individual toolpath segments.

::
  image:Path-InspectWindow.gif[]
  +
  
[.caption]
Above: xref:inspect/inspect.adoc[Inspect Toolpath] tool opens the G-Code Inspection dialog (pre-1.0 screenshot)

To start the simulation use the image:CAM_SimulatorGL.svg[width=32] xref:inspect/simulator.adoc[CAM Simulator] tool (kbd:[P] kbd:[N]). The simulator opens as its own view ([.since]#introduced in 26.3#); choose the quality, press the image:CAM_BPlay.svg[width=24] (Play) button and use the speed buttons.

Press btn:[Close] to end the simulation. (With the xref:inspect/simulator-legacy.adoc[Legacy CAM Simulator], kbd:[P] kbd:[M], btn:[Cancel] removes the cut stock and btn:[OK] keeps it in the document.)

== Postprocess the Job

The final step to generate G-Code for the target mill is to postprocess the Job. This outputs the G-Codes to a file that can be uploaded to the target CNC machine controller. To invoke the Postprocessor:

* Select the Job object in the https://wiki.freecad.org/Tree_View[Tree View]
* Select the image:CAM_Post.svg[width=32] xref:output/post-process.adoc[Post Process] tool (kbd:[P] kbd:[P]).

If the Job has a Machine ([.since]#introduced in 26.3#) the Post Processing dialog opens: review the Operations list, press btn:[Generate Output] on the Output tab to preview the numbered G-code and check the Warnings tab, then btn:[Save to Disk]. Without a Machine, the post-processor chosen on the Output tab runs and the G-code editor opens for review before saving (when "Show editor before writing G-code" is enabled in the CAM GUI preferences). To post-process only some operations, select them and use Post Process Selected (kbd:[P] kbd:[O], [.since]#introduced in 26.3#).
