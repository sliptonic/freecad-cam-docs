== Description

The *Toolbit Library Manager* command opens the _Library Manager_, a modal dialog for creating, editing and organizing Tool Bits and Tool Libraries. [.since]#introduced in 1.1#: the dialog was rewritten. The command has no toolbar button; only xref:tools/add-toolbit.adoc[Add Toolbit…] is in the Tool Commands toolbar.

From here the user can perform all tasks related to Tool Bit management:

* Create, rename, remove, import and export libraries.
* Create, edit, duplicate, import and export Tool Bits.
* Add Tool Bits to libraries by copy/paste, cut/paste or drag and drop, remove them from a library, or delete them from disk.
* Filter the list by Tool Bit type, search by label, and sort by tool number or label.
* The library selected when the dialog is closed becomes the library shown by default in the Toolbit Selector.

Only the creation of new Tool Shapes cannot be done from the Library Manager. This is an advanced topic (see xref:tools/tool-shape.adoc[CAM ToolShape] creation).

The left pane lists _All Toolbits_ followed by every library in the asset directory; the toolbar above it has btn:[Adds a new library], btn:[Removes the library], btn:[Renames the library], btn:[Imports a library] and btn:[Exports the library].

The right pane lists the Tool Bits of the selected library, each with its tool number, label, summary (for example _5 mm 2-flute endmill, 30 mm cutting edge_) and shape icon; above it are a type filter (_All Toolbit Types_), a search box and a sort drop-down (_Sort by Toolbit Number_ / _Sort by Label_), and the buttons btn:[Adds a toolbit], btn:[Imports a toolbit] and btn:[Exports the toolbit].

The window title shows the selected library (_Library Manager - <library name>_); the asset directory is set in menu:Edit[Preferences > CAM > Assets], not in the dialog. All changes are written to disk immediately; closing the dialog (also with kbd:[Esc]) does not undo anything.

== Usage

. There are several ways to open the Toolbit Library Manager:
* Select the menu:CAM[Toolbit Library Manager] option from the menu.
* Open the xref:tools/add-toolbit.adoc[Toolbit Selector] as described and press the btn:[Open Library Editor] button.
. Select a library in the left pane (or _All Toolbits_).
. Use btn:[Adds a toolbit] to create a Tool Bit, btn:[Imports a toolbit] to add one from a file, or paste/drop Tool Bits copied from another library.
. Double-click a Tool Bit (or select it and press kbd:[F2]) to edit it in the _Toolbit Parameter Editor_; the Tool Number field sets its number in the current library.
. Right-click a Tool Bit for menu:Edit[], menu:Copy[] (kbd:[Ctrl+C]), menu:Cut[] (kbd:[Ctrl+X]), menu:Paste[] (kbd:[Ctrl+V]), menu:Duplicate[] (kbd:[Ctrl+D]), menu:Remove from Library[] (kbd:[Del]; only when a library is selected) and menu:Delete from disk[] (kbd:[Shift+Del]; only in _All Toolbits_).
. Close the dialog. The selected library will become the default library for the Toolbit Selector.

== Editing Toolbits

There are several ways to edit the Tool Bits and library:

[upperalpha]
. Sorting: use the _Sort by Toolbit Number_ / _Sort by Label_ drop-down; the choice is remembered between sessions.
. Tool number: double-click the Tool Bit and change *Tool Number* in the editor. Numbers are unique within a library; using a number already taken moves the other Tool Bit to the next free number.
. Double-clicking a Tool Bit opens the _Toolbit Parameter Editor_, where the other properties of the Tool Bit can be edited.

== Drag and drop

[.since]#introduced in 1.1#: Tool Bits can be dragged from the list onto a library in the left pane. The Tool Bit is added to the target library and, when the source is a library (not _All Toolbits_), removed from it. Dropping onto _All Toolbits_ is not possible.

== Filtering

The _All Toolbit Types_ drop-down filters the list by shape type; [.since]#26.3 and later# subtypes (for example Drill → jobber, stub, spot) are listed indented under their type. The search box matches the label, the summary and the type name.

== Import

btn:[Imports a toolbit] requires a library to be selected (message: _Select a library first_). Importing a library (`.fctl` or Camotics `.json`) also imports the Tool Bits it references if a `Bit` folder exists next to the file.
