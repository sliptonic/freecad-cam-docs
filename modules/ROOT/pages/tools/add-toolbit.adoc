== Description

The *Add Toolbit…* command opens the _Toolbit Selector_, a dialog that shows the Tool Bits of a library and creates Tool Controllers in the active Job from the selected Tool Bits. Despite the command name it is a dialog, not a dock panel. [.since]#introduced in 1.1#: the Toolbit Selector replaced the earlier Tool Bit dock panel.

Double-clicking a Tool Bit creates one Tool Controller for it. Selecting several Tool Bits and pressing btn:[Add to Job] creates one Tool Controller per selected Tool Bit. The btn:[Add to Job] button is only enabled when a Tool Bit is selected and the document contains a Job.

The first row of the dialog holds the library drop-down (the last used library is preselected), the _All Toolbit Types_ filter and the sort drop-down; below it is a search box. Each list entry shows the tool number in the selected library, the label, a one-line summary and the shape icon. The buttons at the bottom are btn:[Open Library Editor] (opens the xref:tools/library-manager.adoc[Library Manager]), btn:[Add to Job] and btn:[Close].

If the document contains no Job, the message _Create a Job first_ is shown. If it contains several Jobs, a dialog asks which Job to add the Tool Controllers to. The new Tool Controller is named _TC: <Tool Bit label>_, gets the Tool Bit's number in the selected library as *Tool Number* and the Tool Bit's *Spindle Direction*.

The same Tool Bit browser is used by the Job editor (Tools tab → btn:[Add], dialog _Select Toolbit_, which additionally offers _All Tools_; Tool Bits taken from _All Tools_ get the next free tool number of the Job) and by the _Tool controller_ drop-down of an operation's task panel, whose last entry opens the Toolbit Selector to create a new Tool Controller.

== Usage

=== Create Tool Controllers

. There are several ways to open the Toolbit Selector:
* Press the image:CAM_ToolTable.svg[width=16] btn:[Add Toolbit…] button in the Tool Commands toolbar.
* Select the menu:CAM[Add Toolbit…] option from the menu.
* Use the keyboard shortcut: kbd:[P] then kbd:[T].
. Select a library in the drop-down.
. Double-click a Tool Bit, or select one or more Tool Bits and press btn:[Add to Job].
